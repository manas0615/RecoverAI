# Historical Reports Archive

This directory contains historical architecture documents, deep dives, and evaluations generated during earlier phases of the RecoverAI buildathon journey. 

## Context
These documents are preserved as evidence of the engineering process. However, they may contain:
- Deprecated architectural concepts (e.g., discussions of open-loop architectures).
- Pre-fix vulnerability states.
- Outdated threshold values or metric expectations.

**For the current authoritative architecture, please refer to the main `docs/` directory.**

## Index
- `architecture.md`: Historical topology design.
- `evaluation.md`: Massive early-stage evaluation planning document.
- `failure_recovery.md`: Early resilience theory and matrix mapping.
- `policy_and_safety.md`: Legacy rules engine specifications.
- `razorpay_integration.md`: Early provider integration research.
- `benchmark_1500_seed42.md`: The raw frozen L3 benchmark artifact (Current/Valid).
- `FINAL_EVIDENCE_PACK.md`: A historical checkpoint report.
