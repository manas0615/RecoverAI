## 6. 401 Root Cause
Caused by a missing or mismatched `VITE_API_KEY` in the browser client compared to `FRONTEND_API_KEY` on the server. This is an operational configuration issue, not a user login failure.

## 7. 403 Handling
Occurs if the frontend client attempts to call orchestrator-only routes (e.g., POST `/mcp/execute`). Handled gracefully by `AccessBoundary` presenting an "Insufficient Permissions" shield alert.

## 8. Authentication Decision
RecoverAI does NOT require login or registration screens. It uses an infrastructure API key (`VITE_API_KEY`) for read-only access.

## 9. API Client Audit
